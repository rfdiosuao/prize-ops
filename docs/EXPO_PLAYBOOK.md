# 游园会 / 展览式评审 作战手册（EXPO MODE）

> 模块定位：跨阶段心法。适用于**评分者会移动、停留时间极短、作品需要被反复上手**的赛制（游园会、开放日、Expo 展评、观众投票制）。
> 蒸馏来源：2026-09 深圳站备战过程 + 公开赛制报道（来源与采集日期见各节标注）
> 采集日期：2026-09-15
>
> ⚠️ **本模块不承诺获奖概率，也不主张通用评分权重。** 其中的时长、比例、死因占比均为**推断**，须以当场赛规与实测为准。凡"需要核实"的项，不得当作已知条件。

---

## 一、先判断：你面对的到底是哪一种赛制

**第一件事不是设计作品，是识别赛制。** 三种赛制对作品的要求完全不同。

| 赛制 | 评分者行为 | 你必须做到 | 你不需要做 |
|---|---|---|---|
| **路演制** | 集中坐在台下，看 3–5 分钟演示 | 叙事结构、deck、口播 | 展位、陌生人上手 |
| **游园制** | 走动、逐个展位停 10 秒–3 分钟 | **零讲解可用 + 极短停留的记忆点** | 长叙事、精致 deck |
| **混合制（最常见）** | 先游园巡场，后集中路演 | **两套都要满足** | —— |

> **混合制是最容易吃亏的赛制**，因为大多数人只准备一套材料，然后发现自己要么过不了巡场、要么过不了路演。

### 1.1 必须向主办方核实的 5 个问题（开赛第一天就问掉）

这一节的价值高于本文其余部分之和。**这 5 个答案会改变你的资源分配，而它们通常不会写在海报上。**

| # | 要问的问题 | 为什么决定策略 |
|---|---|---|
| 1 | **晋级到下一环节，由谁决定？** 评委评分 / 观众投票 / 加权？ | 决定你把资源压在"可验证性"还是"传播性" |
| 2 | **评分的各维度与权重？** | 决定材料配比 |
| 3 | **每个展位的平均停留时长？** | 决定你的首屏必须多快说清事 |
| 4 | **某一环节的晋级比例？** | `<30%` 必须抢"哇时刻"；宽松则可压缩现场投入 |
| 5 | **专项奖的参评方式与统计口径？**（是否需提前报名/登记） | 有些奖**无法在赛内补办**，必须 Day1 就提交 |

**证据等级标注习惯**：把每个答案标为 `official`（官方书面）/ `staff_verbal`（工作人员口头，须注明是谁）/ `inference`（推断）。**口头信息不得升级为官方事实**——这是本仓库既有纪律。

## 二、漏斗重建：游园制多了一道隐形淘汰层

一般赛制的漏斗是 `提交 → 评审 → 路演`。
**游园制的漏斗多了一层，而且它是隐形的：**

```
封板
 └─▶ 【隐形层】陌生人零讲解上手 + 评委巡场读代码   ← 大多数队伍死在这里
      └─▶ 路演（若有）
           └─▶ 终审
```

### 2.1 这一层的三个特征

1. **没有宣布，也没有提示。** 你不会被告知"这是初赛"，它看起来像开放日。
2. **评委是移动的、被打断的。** 他可能在你的展位停留 40 秒就被下一件东西吸走。
3. **观众是"不需要对你负责"的评分者。** 他会直接走开，而且不会告诉你为什么。

### 2.2 主要死因（**推断**，须以实测校准）

| 死因 | 典型表现 | 大致占比（推断） |
|---|---|---|
| **不知道你在做什么** | 路过 3 秒没看懂，直接走 | 最高 |
| **不知道怎么开始** | 看懂了但找不到入口 | 次之 |
| **上手后没有反馈** | 点了一下没反应，放弃 | 次之 |
| **没有记忆点** | 玩完了什么都没留下 | 次之 |

> 校准方法：用第十节的检查清单，在赛前找未参与者实测，把"在哪一步停住"记下来。**这是可用性反馈，不要包装成需求验证。**

## 三、双评分者模型：游园现场有两个人同时在看你

这是游园制最核心的结构性事实。

| | **观众** | **巡场评委** |
|---|---|---|
| 停留时长 | 10 秒 – 1 分钟 | 1 – 3 分钟 |
| 在找什么 | 好玩、能拍照、能带走 | 证据、代码、技术选择 |
| 判断依据 | 体验感 | 可验证性 |
| 失败方式 | 直接走开，不解释 | 不追问，直接离开 |
| 你要给的 | 零讲解入口 + 可分享/可带走的产物 | 主张-证据表 + 架构图 + 可当场重放的东西 |

### 3.1 铁律：不许偏科

**最常见的致命错误是：为了讨好观众，牺牲了可验证性。**

- 观众票通常只绑**一个**观众选择类奖项；
- 而"晋级"通常与评委评分强相关（多数赛制如此，**须核实**）；
- 一个"很好玩但读不出技术纵深"的作品，能拿传播奖，拿不到冠军。

**正确做法**：把两套材料做成**同一套物料的两个入口**——展位主视觉面向观众，展位侧板/桌面文件面向评委。**不要做两个作品。**

## 四、四层台阶：把"讲解"从你的嘴上搬走（本模块核心）

### 4.1 为什么必须这样做

游园制里你要对**每一个人**重复讲。这会遇到三个无法靠努力解决的物理限制：

| 限制 | 后果 |
|---|---|
| **嗓子** | 讲 100+ 遍后人会失声、会烦躁、会偷工减料 |
| **一致性** | 第 40 遍和第 5 遍讲得不一样，**准确率必然下降** |
| **识别成本** | 你不知道谁是评委谁是路人，无法差异化 |

**结论：不要靠讲。要靠"递"。**

### 4.2 台阶设计

把信息拆成四层，**让听众自己选深度**——你不需要判断他是谁。

| 层 | 停留 | 谁承担讲解 | 你要准备的东西 |
|---|---|---|---|
| **L0** | 0–3 秒 | **展位承担，你不开口** | 大字主视觉 + 一句反问 + 一个动作指令 |
| **L1** | 10 秒 | 你说 **1 句 + 做 1 个动作** | 一句钩子 + 一个递出去的东西 |
| **L2** | 60 秒 | **对方自己完成，你闭嘴** | 让他亲手操作 + 屏幕上给对照/反馈 |
| **L3** | 3 分钟 | 你说 2 句 | 机制 1 句 + 立意 1 句 → 然后进代码 |

**关键**：L0 交给展位，**你的嗓子只承担 L1 和 L2**。这样一天只需重复 2 句话，走样概率趋近于零。

### 4.3 L1 的设计规则（一天要说 200 遍的那一句）

**规则 1：必须是"介绍一个存在"，不是"介绍一个产品"。**

| ❌ 介绍产品 | ✅ 介绍一个存在 |
|---|---|
| 「我们做了一个 XX 系统，它能……」 | 「它只能记住 12 个人。」 |
| 「我们基于大模型做了 XX 算法」 | 「它每想一次，就走样一点。」 |

**为什么**：前者触发对方的**评估模式**（他开始判断你的产品好不好）；后者触发**认识模式**（他开始好奇它是谁）。**后者才让人停下来。**

**规则 2：第二句必须是"邀请"，不是"解释"。**
邀请只需要对方做一个动作；解释需要对方先有理解框架——**而他没有**。

**规则 3：第一句给"稀缺"或"矛盾"。**
人对"只有 12 个""它自己不知道"这类结构有反应。人对"这是一个 XX 平台"没有反应。

**规则 4：必须是问句或短陈述，能一口气说完。**
超过 15 个字就会在噪声中被削掉一半。**实测方法见第十节。**

### 4.4 L2 的设计规则

**L2 的目标不是让你讲，是让对方自己撞见那件事。**

设计要点：
1. 他做**一个**动作（不是三个）；
2. 屏幕上出现**一个对照**（他的输入 vs 系统的输出，并排）；
3. 底部有一行**替你收尾的小字**（"它已经这样记错了 214 次"）；
4. **然后你闭嘴。** 那 10 秒是属于他的。

> **一个人自己撞见的事，比一个人听来的事，可信得多。**

## 五、自解释作品原则

### 5.1 唯一判断标准

> **如果这个东西需要我开口解释，说明它还没做完。**

这不是修辞要求，是可执行的工程要求。它反过来约束了作品设计：**别把"理解"这一步留给观众的大脑，要把它做进屏幕里。**

### 5.2 三个可复用的手段

| 手段 | 做法 | 为什么有效 |
|---|---|---|
| **实体对照物** | 做一份可以拿在手上、需要"翻过来"才知道结果的实物 | 人对手上物体的动作是本能；对屏幕上的文字需要注意力 |
| **让观众亲手制造那个现象** | 不展示结果，而是让观众的操作**产生**那个结果 | 自己造成的现象，不需要被说服 |
| **展位写"问句 + 动作"，不写"我们是什么"** | 「它记得的你，和你记得的你，是同一个吗？」+「拿起一张卡，翻过来。」 | **人对动作的服从度，远高于对陈述的理解度** |

### 5.3 展位 10 秒法则

路过的人 10 秒内必须看到三件事，缺一不可：

1. **主视觉**（一句能记住的话）
2. **一句反问**（比陈述更抓人）
3. **一个动作指令**（直接告诉他做什么）

外加一个**定位标签**（赛道名/类别），让评审一秒归类。

## 六、话术规范

### 6.1 术语替换的判据（给方法，不是给词表）

逐条检查你的每一句话：

> **这句话能不能说给一个完全不懂你这行的人听？不能，就换掉。**

替换方向：
| 抽象机制词 | 换成 |
|---|---|
| 指标名（保真度、召回率…） | 「它记得的，和你说的差了多远」 |
| 架构词（三级链路、多智能体…） | 「它每回忆一次，就再走样一点」 |
| 领域缩写 / 学术名词 | 一个日常动作或感受 |

### 6.2 黑名单：三类说了就掉分的话

| 类型 | 例子 | 为什么 |
|---|---|---|
| **触发评估模式的开场** | 「我们做了一个 XX 系统」 | 对方开始判断产品，而不是体验它 |
| **顺序倒置** | 还没让他看到现象就讲算法原理 | 他在没有现象的情况下无法理解原理 |
| **开场自曝缺口** | 「这个功能还没做完」 | 等于开场自己减分。**缺口留给提问环节主动坦白** |

> 第三条尤其重要：**开场只讲已经成立的，未完成的诚实留给被问到时。**

## 七、视频承担的是"时间维度"

现场无法演示两类东西：**时间**和**过程**。视频的唯一不可替代价值就在这里。

### 7.1 设计规则

| 项 | 规则 |
|---|---|
| **任务** | 不是解释项目，是**压缩时间** |
| **旁白** | **不要。** 用硬字幕——现场很吵，而且"不解释"本身可能就是你的主张 |
| **时长** | 2 分 30 秒以内。超过没人看完 |
| **用途** | 展位循环 / **翻车兜底** / 路演精华版 |
| **首帧** | 直接给那个最有冲击力的对照，不要 logo 开场 |

### 7.2 拍摄时点（错过补不回来）

1. **第一天就要开录。** 延时、初始状态、"第一条记录"——**这些素材只有第一天有**。
2. **中途的真实用户环节**是最珍贵的一批素材，安排专人拍。
3. **高潮环节双机位**：一台拍屏幕，一台**拍围观者的脸**。**人群的沉默比任何旁白都有力。**

## 八、升华的位置规则

**升华需要前置语境。** 顺序反了，升华就变成说教。

| 场合 | 用不用升华 |
|---|---|
| L0 展位大字 | ❌ |
| L1（一天说 200 遍的那 2 句） | ❌ **绝对不用** |
| L2（对方上手那 60 秒） | ❌ |
| L3（开始追问的人） | ✅ |
| 视频片尾 | ✅ |
| 路演最后一句 | ✅ |
| 媒体/社群文案 | ✅ |

> 对一个刚停下来的人讲背景、历史、理论，等于对刚认识的人讲你的童年。**先让他自己撞见现象，再给他纵深。**

### 8.1 升华的红线

**升华 ≠ 过度声称。** 升得越高，越会被要求给证据。

| 永远不说 | 正确姿态 |
|---|---|
| 「它有人格/有意识」 | 「我们不声称任何超出证据的东西」（然后给现象） |
| 「科学证明了 X」 | 「有实验表明 X」（并标明是哪一类结论） |
| 「这是第一个……」 | 除非查证过，否则必被打脸 |

**引用科学依据时的分档纪律**：

| 档 | 可以说 |
|---|---|
| 学界共识级（经典实验、反复验证） | 「经典实验表明」「已被反复验证」 |
| 机制假说级（仍有争论 / 有边界条件） | 「有研究表明」「这是一个机制假说」——**不能说"已被证明"** |
| 自己的推论 | 「我们推测」 |

> **对科学性存疑的领域，主动说明分寸反而加分**；被当场问出来才丢分。

## 九、资源判断：呈现层不是装饰

**这是游园制最容易被误判的资源问题。**

| 错误认知 | 事实 |
|---|---|
| "呈现是最后补的包装" | **呈现层是开发后期的独立工作量** |
| "把功能做完自然会好看" | 陌生人不会替你补上理解这一步 |
| "写好 deck 就够了" | 游园制里 deck 可能没有展示机会 |

### 排期含义

- **功能冻结点要设在最后一天之前**，把封板前的一整段时间留给呈现层（展位、卡片、视频、彩排）。
- **实测环节必须早于封板**，因为改的是呈现，而呈现改动会反过来要求功能微调。
- **不要等到最后一天才第一次让陌生人上手。** 那等于把整个隐形淘汰层留给了运气。

## 十、检查清单（赛前实测用）

### 10.1 五分钟实测法

找 **5 个完全不了解项目的人**，只做 L0 + L1，**然后闭嘴**，看他接下来做什么。

| 观察结果 | 判断 | 动作 |
|---|---|---|
| 3 人以上直接上手 | ✅ 通过 | 锁定，不再改 |
| 有人问「这是什么？」 | ⚠️ L1 不够具体 | 加强稀缺/矛盾 |
| 有人说出一个**错误的类比** | ❌ **严重** | L1 被误读，必须换句 |
| 有人不停顿直接走 | ❌ L0 失效 | 改主视觉，加大对比 |
| 有人问出意料之外的问题 | ⚠️ 记下来 | 这些就是评审会问的问题 |

### 10.2 提交前自检

- [ ] 主视觉能让路过者 3 秒内读懂"这是什么类别的工作"
- [ ] 有一句能当广告语的 slogan
- [ ] 有一句反问（不是陈述）
- [ ] 有一个明确的动作指令写在展位上
- [ ] 5 人实测中 3 人以上零讲解上手
- [ ] 证据类材料（架构图/主张-证据表）在展位**侧面**，不干扰主视觉
- [ ] 断网/设备故障有兜底（视频 / 本地降级 / 双机）
- [ ] 视频 ≤ 2 分 30 秒、无旁白、有硬字幕
- [ ] 升华只出现在 L3 / 视频片尾 / 收尾，**不在 L1**
- [ ] 每一句声称都能对应到证据，**没有超出证据的表述**
- [ ] 提前确认哪些专项奖需要赛前报名（不可赛内补办）

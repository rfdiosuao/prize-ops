PrizeOps v2.0

PrizeOps · 七阶段工作流与游园会展示支线

从发现比赛、组队交付、现场展示到赛后复盘；每一步以当场规则和实际验收为准

现场准备原则
先完成可重复的主链，再让陌生人看懂并上手
具体评分以当场官方规则为准；SUMMON 游园会复盘提出的 60/40 仅是备战配比
可配置自动化 人机协作 阶段产出 反馈循环
1
情报雷达 手动运行 / 可配置定时
触发：手动运行，或自行配置 cron
动作：运行现有赛事抓取脚本 → 核对来源与截止日期 → 按位置、预算和赛道筛选；飞书、邮件等通知需另行配置
关联模块：01-radar/ fetch_hackathons.py + send_feishu.py
📦 产出：待核验的比赛清单；配置通知后可选择推送
↓
2
筛选罗盘 人机协作 · 双通道分流
触发：收到推送后，选择感兴趣的比赛
动作：用 competition-award-pathfinder 分析规则 → 提取硬门槛 → 重建评审漏斗 → 对比 ≥3 条赛道 → 判断比赛类型
关联模块：02-compass/ + competition-award-pathfinder
⚡ 轻量通道（线上提交制）
检查已有项目是否符合本场要求 → 核对提交材料与规则 → 人工确认提交 → 记录结果并复盘；自动化须按实际配置核验
AUTO_ENTRY.md
🔥 重量通道（高奖金/线下）
进入阶段3深度分析 → 创意生成 → UI设计 → 开发 → 路演 → 现场参赛 → 复盘
继续阶段 3→7
📦 产出：参赛决策报告（推荐赛道 + 通道选择 + 倒推时间线）
↓ 重量通道继续
3
深度分析 + 创意生成 人机协作 · 先核实赛题
触发：确定走重量通道后
动作：深度拆解比赛规则 → 用「反惯性·多视角·闭环验证」提示词生成 idea → 悬置第一反应 → ≥3 独立视角审视 → 把握度分级 → 倒推评分维度生成 3-5 个差异化 idea
关联模块：03-pathfinder/ + Step 7.5 创意生成
📦 产出：3-5 个差异化 idea + 推荐路线 + 核心 demo 定义
↓
4
作品武器库 人机协作 · UI 一定要炸
触发：idea 确定后
动作：从获奖作品档案选风格 → UI设计规范 → 交互逻辑 → 鼠标交互动作 → 首屏流体动效 → 倒推制作顺序（先图片资产 or 先框架）→ 按最小可演示闭环收敛功能
关联模块：04-arsenal/ + 05-stage/ 5个蒸馏文档 + archive-miaoda 13个获奖作品
📦 产出：UI设计规范 + 交互原型 + 图片资产清单 + 最小MVP功能清单
↓
5
执行冲刺 人机协作 · 最小可演示闭环
触发：设计规范确定后
动作：按制作流程执行 → 图片资产先行 → 搭框架填充 → 先让真实输入、执行和回执连续跑通 → 验证陌生人能上手 → 再做必要的呈现
关联模块：06-sprint/ minimum-demo-loop.md + PRODUCTION_FLOW.md
📦 产出：可运行 demo（3分钟可演示的最小闭环）+ 演示视频（45-90秒）
↓
6
路演舞台 人机协作 · 会讲故事 · 丝滑动画
触发：demo 完成后
动作：写逐字稿 → Gamma生成PPT初稿 → PowerPoint精修动画（统一Fade + 缓入缓出 + Morph转场 + 嵌入演示视频）→ 10页5分钟模板 → 排练配合语速 → 答辩Q&A预案
关联模块：06-sprint/PITCH_DECK.md 丝滑动画PPT指南
📦 产出：路演稿 + 丝滑动画PPT（含嵌入视频）+ 答辩预案
↓
游园会展示（适用时）
动作：确认本场赛制与评分 → 固定一条真实主链 → 让陌生人自己上手 → 展示输入、决定和设备回执 → 准备已标注的故障兜底。
赛前一天：功能冻结、3 次完整演示、2 次讲解彩排、物料检查，不熬夜。
备战配比：项目完成度约 60% / 讲解状态约 40%，是参赛者经验，不是官方评分权重。
流程：游园会执行手册 · SUMMON 案例
📦 产出：可重复的展位 Demo + 简短讲解 + 故障兜底 + 现场观察记录
7
复盘结晶 整理证据 · 可选公开 PR
触发：比赛结束（获奖 or 未获奖）
动作：按证据整理目标与结果、全流程时间线、做对的事、问题与改进、下次三个重点；公开发布前检查隐私与授权，按需提交 PR
关联模块：07-crystal/ prizeops-review Skill
📦 产出：复盘文档 + 可执行改进项；经授权后公开提交 PR
⚡ 轻量通道补充：赛果跟踪（可配置）
提交后记录官方状态页和查询日期 → 定期核验初审、入围与赛果 → 结果确认后复盘；定时访问和通知只在已配置、已测试时启用
🔄 反馈循环（让系统越跑越强 · 越多人用越强）
阶段7复盘PR → 优化阶段1情报源（新增/淘汰信息源、调整筛选阈值）
阶段7复盘PR → 迭代阶段3创意方法论（区分过程证据与赛事结果，不用单次结果推断因果）
阶段7获奖作品 → 补充阶段4 UI档案（新增获奖作品拆解，扩充风格库）
阶段7复盘PR → 优化阶段6路演模板（沉淀有效的叙事结构和动画模式）

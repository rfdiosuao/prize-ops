# 复盘档案库

推荐入口：[安装复盘 Skill](../docs/one-word-review.md)，在自己的项目中说“复盘”。首次启用后自动使用 GitHub 登录及个人 Fork 向这里提交报告。只收整理后的经验文档，不收源码包、原始聊天和私人数据。

这里存放经整理的项目复盘。推荐按 [prizeops-review Skill](../skills/prizeops-review/SKILL.md) 收集证据、检查公开范围，再按本次授权提交 PR；旧版问卷脚本仍保留为手动入口。

## 提交方式

使用 Skill 或旧版脚本整理报告后：

1. 核对目标、结果、全流程时间线和证据缺口。
2. 将可公开的 Markdown 放入本目录；原始聊天、密钥与私人资料留在项目本地。
3. 在得到本次公开授权后提交 PR，由维护者审阅。

## 文档命名规范

`{日期}-{比赛名}-{队名}.md`

例如：`2026-11-20-2026微信小程序开发大赛-城市盲盒.md`

## 如何贡献复盘

1. 阅读 [复盘流程](../skills/prizeops-review/SKILL.md)，或使用旧版问卷脚本。
2. 核对事实、公开范围与引用链接；不把自评当作赛事官方评分。
3. 经授权后提交 PR，社区评审后合并。

# 复盘档案库

这里存放所有参赛者提交的复盘文档，由 `07-crystal/review_hackathon.py` 自动生成并通过 PR 提交。

## 提交方式

运行复盘脚本后，脚本会自动：

1. 创建分支 `review/{比赛名}-{队名}-{日期}`
2. 生成复盘文档到本目录
3. 创建 PR 到 main 分支

## 团队实战复盘

- [养令 · 复客松二等奖复盘（2026-09-13）](2026-09-13-复客松-养令-二等奖复盘.md)：七项可复用做法、演讲后百川接入的时间边界，以及下一次的三个优先改进项。奖项由参赛者确认，非评委评分归因报告。

## 文档命名规范

`{日期}-{比赛名}-{队名}.md`

例如：`2026-11-20-2026微信小程序开发大赛-城市盲盒.md`

## 如何贡献复盘

1. 运行 `python3 07-crystal/review_hackathon.py`
2. 按提示回答问题
3. 脚本自动提 PR，社区评审后合并
